# RibhShare – Project Lifecycle

## Overview

Every project follows a standard lifecycle from idea to profit distribution.

```
Idea

↓

Project Created

↓

CEO Review

↓

Approved

↓

Capital Raising

↓

Project Execution

↓

Realised Profit

↓

Profit Distribution

↓

Project Closed
```
