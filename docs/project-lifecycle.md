# Prism Capital — Project Lifecycle

```
Idea
  ↓
Project created (LM) — INITIATION / PENDING
  ↓
CEO review — APPROVED → ACCEPTANCE
  ↓
Capital raising — invites, pledges, proofs, LM confirm
  ↓
Target reached (or early Progress) — PROGRESS + raise fee reserved
  ↓
Execution — owner drawdowns, activity updates
  ↓
Profit — owner proposes / LM declares → CEO four-eyes → notices + ledger
  ↓
Withdrawals — investor & owner profit requests
  ↓
FINAL declaration — END + capital return on notices
```

Actors: **LM** (Prism ops), **CEO** (governance), **PROJECT_OWNER** (originator), **INVESTOR** (capital).
