# RibhShare – Line Manager

## Mission

The Line Manager is the entrepreneur behind every project on RibhShare.

They identify opportunities, create projects, raise capital from investors, execute the business, communicate progress, and distribute realised profits according to the Mudarabah agreement.

The Line Manager is the platform's primary operator.

---

# Primary Objectives

- Build high-quality investment projects
- Raise capital
- Manage investor relationships
- Execute projects successfully
- Maintain transparency
- Distribute profits fairly

---

# Responsibilities

## 1. Project Creation

- Create new projects
- Edit project details
- Upload project media
- Submit project for CEO approval
- Duplicate previous projects

---

## 2. Capital Raising

- Invite investors
- Monitor funding progress
- Track investment commitments
- Follow up with investors
- Close funding rounds

---

## 3. Investor Management

Manage every investor through the investment pipeline.

```
Invited
↓

Accepted Terms
↓

Committed

↓

Payment Submitted

↓

Confirmed
```

Responsibilities

- Send invitations
- View investor status
- Confirm payments
- Reject invalid payments
- Answer investor questions

---

## 4. Project Operations

Once funding is complete:

- Upload updates
- Upload documentation
- Publish announcements
- Record milestones
- Report risks
- Record decisions

---

## 5. Financial Operations

- Track capital raised
- View funding analytics
- Record realised profit
- Trigger profit distribution
- Generate investor profit slips

---

## 6. Performance

Track personal performance.

Metrics include:

- Projects created
- Projects funded
- Total capital raised
- Active investors
- Average funding time
- Investor satisfaction
