# Prism Capital — Project Owner

## Mission

The Project Owner is the **originator** of a deal. Prism’s Line Manager creates the listing and raises capital; the owner operates the project after funding (drawdowns, profit proposals) and receives the agreed **manager share** of distributable profit.

---

## Responsibilities

- Review project terms with Prism after assignment
- Request **fund drawdowns** (purpose, bank details, support docs)
- **Propose realised profit** to the Line Manager (LM forwards to CEO)
- Withdraw approved manager-share profit
- Message the Prism Line Manager (no direct investor DMs)

---

## Cannot

- Create projects or invite investors
- Confirm payment proofs
- Approve profit declarations
- See other Prism deals or the investor register / ledger / audit tabs
